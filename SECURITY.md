# Security Policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use the repository host's private vulnerability-reporting channel when it becomes available, or contact the maintainer privately.

Do not include credentials, raw audio, transcripts, provider payloads, or other user content in a report. Provide a minimal content-free reproduction whenever possible.

## Scope

Security-sensitive areas include private-output enforcement, route changes, stale-flow isolation, bounded buffers, content-free diagnostics, and accidental persistence.
